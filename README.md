# Витрина данных для маркетплейса KarpovZone

## Цель проекта

Построить витрину данных для аналитиков маркетплейса: подготовить показатели по карточкам товаров и отчёты по продавцам и брендам.

## Стек

Python, PySpark, SQL, Apache Airflow, Greenplum, S3, Kubernetes, Git.

## Что сделано

- Разработал Spark-задачу для чтения Parquet-файлов из S3 и расчёта шести дополнительных показателей: возвратов, потенциальной и фактической выручки, средних продаж в день, срока распродажи остатков и относительного рейтинга товаров.
- Настроил сохранение обработанных данных в отдельную папку S3.
- Собрал DAG из пяти задач в Airflow: запуск Spark в Kubernetes, ожидание завершения обработки, создание внешней таблицы и двух представлений в Greenplum.
- Подключил обработанные данные к Greenplum через PXF.
- Подготовил отчёты по продавцам с избытком остатков и по выручке и ассортименту брендов.

## Результат

Реализовал единый пайплайн от исходных файлов в озере данных до витрины в Greenplum. Обработанные данные доступны для SQL-запросов, а представления позволяют анализировать остатки, выручку и ассортимент.
